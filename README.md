# Frontend Portfolio

웹 퍼블리셔 경험을 기반으로 React 프론트엔드 개발 역량을 확장해가는 과정을 정리한 포트폴리오 사이트입니다.

## Projects

### React Shop

- React 기반 쇼핑몰 프로젝트
- 장바구니, 찜 목록, 최근 본 상품 구현
- Zustand, LocalStorage 활용

### Admin Dashboard

- 관리자 대시보드 프로젝트
- CRUD, 검색, 필터, 페이지네이션 구현
- Recharts, Zustand, Dark Mode 적용

### Publisher Portfolio

- 반응형 웹 퍼블리싱 프로젝트
- HTML/CSS/JavaScript 기반 UI 구현
